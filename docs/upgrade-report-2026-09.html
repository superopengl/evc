EasyValueCheck — Platform Upgrade Report

Branch upgrade/node-24  ·  2a08f7b3 → a215eb2b  ·  91 commits  ·  3–6 Sep 2026  ·  349 files, ~20.8k added / ~32.7k removed (net −12k lines)

Every major runtime, framework and library the product depends on was lifted onto a current, supported version. 48 known security advisories in the frontend were cleared to zero. The product surface is unchanged; the codebase is ~12k lines smaller. The driver was risk, not novelty — Node 18, Create React App, AWS SDK v2, TypeORM 0.2, rxjs 6, react-router 5 and antd 4 were all past end-of-life, meaning no security patches and no viable path to future upgrades. The PostgreSQL 14 → 18 upgrade is written but not yet executed, and PG14 reaches end of life in November 2026. Its driver script has since been removed from the repo and is recoverable from commit a215eb2b.
